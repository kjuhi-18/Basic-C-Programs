## ⚙️ How to Run Any Program

### ✅ Compile
```bash
gcc filename.c -o output
```

### ✅ Run
```bash
./output
```

> 💡 If your file name has spaces, use quotes:
```bash
gcc "file name.c" -o output
```

> 💡 If you use `math.h`, compile using:
```bash
gcc code.c -o output -lm
```
